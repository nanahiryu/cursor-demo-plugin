# 仕様書

## コンセプト

(誰に) 人事部のメンバーに
(何を) 勤続年数がわかりやすくなったと
言ってもらう

## アプリ設計

| フィールド名 | フィールドコード | 必須 | 重複不可 | 備考                     |
| ------------ | ---------------- | ---- | -------- | ------------------------ |
| ユーザー ID  | user_id          | x    | x        |                          |
| ユーザー名   | user_name        | x    |          |                          |
| 年齢         | age              | x    |          |                          |
| 勤続年数     | working_year     | x    |          | このプラグインの制御対象 |

## 要件

- 経験年数が5年以上と未満で勤続年数フィールドの背景色が色分けされていること
- 5年以上、5年未満それぞれで背景色を設定できること
