# 詳細設計

## プラグインのデータ構造

例)

```json
{
  "highColor": "#000000",
  "lowColor": "#000000"
}
```

- 必ず`^#[A-Fa-f0-9]{6}$`の形式にフォーマットされた後で保存される
- 従って、次回取得する際には`^#[A-Fa-f0-9]{6}$`の形式で取得される

## 設定画面

- 2つのColorPickerでカラーコードを「勤続年数5年以上」「勤続年数5年未満」それぞれのケースで独立に設定できるようにする
  - 文字列の入力のみ動作を保証できればok
- それぞれのフィールドは空値や無効なカラーコードを入力できないようにする
  - カラーコードは `^#([A-Fa-f0-9]{6}|[A-Fa-f0-9]{3})$` の正規表現に一致する, または特定の文字色を表す文字列のみ許可する
- 入力された場合、元のカラーコードから変更されないようにする
- 前回保存したカラーコードが初期値として入力されるようにする

## 一覧画面

- 一覧画面表示時、勤続年数に応じて設定画面で指定したカラーコードに応じた背景色2色に色分けされる
