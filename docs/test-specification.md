# テスト仕様書

## 設定画面テスト

| テスト番号 | タイトル                     |
| ---------- | ---------------------------- |
| 1          | カラーピッカー機能の確認     |
| 2          | 無効なカラーコードの入力制限 |
| 3          | 空値の入力制限               |
| 4          | 有効なカラーコードの手動入力 |
| 5          | 初期値の確認                 |

---

### 事前準備

※この事前準備は設定画面テストの全てのテストケース実行前に毎回実施する。

1. 設定画面を開く
2. 「勤続年数5年以上」のカラーコードに「#000000」（黒色）を設定する
3. 「勤続年数5年未満」のカラーコードに「#000000」（黒色）を設定する
4. 設定を保存する

---

### 1. カラーピッカー機能の確認

1. 「勤続年数5年以上」のカラーピッカーを開く
2. 赤色（#FF0000）を選択する
3. 「勤続年数5年未満」のカラーピッカーを開く
4. 青色（#00F）を選択する
5. 設定を保存する
6. 「勤続年数5年以上」のカラーコードが「#FF0000」（赤色）に、「勤続年数5年未満」のカラーコードが「#00F」（青色）に正しく設定されていることを確認する

---

### 2. 無効なカラーコードの入力制限

1. 「勤続年数5年以上」の入力フィールドに無効なカラーコード「#XYZ」を入力する
2. 「勤続年数5年未満」の入力フィールドに無効なカラーコード「red」を入力する
3. 別の場所をクリックする
4. 「勤続年数5年以上」のカラーコードが事前に設定した「#000000」（黒色）のままで変更されていないことを確認する
5. 「勤続年数5年未満」のカラーコードが事前に設定した「#000000」（黒色）のままで変更されていないことを確認する

---

### 3. 空値の入力制限

1. 「勤続年数5年以上」の入力フィールドを空にする
2. 「勤続年数5年未満」の入力フィールドを空にする
3. 別の場所をクリックする
4. 「勤続年数5年以上」のカラーコードが事前に設定した「#000000」（黒色）のままで変更されていないことを確認する
5. 「勤続年数5年未満」のカラーコードが事前に設定した「#000000」（黒色）のままで変更されていないことを確認する

---

### 4. 有効なカラーコードの手動入力

1. 「勤続年数5年以上」の入力フィールドに有効なカラーコード「#FF0000」（赤色）を入力する
2. 「勤続年数5年未満」の入力フィールドに有効なカラーコード「#00FF00」（緑色）を入力する
3. 設定を保存する
4. 入力したカラーコードが正しく反映されることを確認する

---

### 5. 初期値の確認

1. 「勤続年数5年以上」のカラーコードを「#FF0000」（赤色）に、「勤続年数5年未満」のカラーコードを「#00FF00」（緑色）に設定する
2. 設定を保存する
3. 再度設定画面を開く
4. 「勤続年数5年以上」のカラーコード「#FF0000」（赤色）と「勤続年数5年未満」のカラーコード「#00FF00」（緑色）が初期値として表示されていることを確認する

## 一覧画面テスト

| テスト番号 | タイトル                         |
| ---------- | -------------------------------- |
| 6          | 色分け表示と設定変更後の反映確認 |

---

### 事前準備

※この事前準備は一覧画面テストの全てのテストケース実行前に毎回実施する。

1. 設定画面を開く
2. 「勤続年数5年以上」のカラーコードに「#000000」（黒色）を設定する
3. 「勤続年数5年未満」のカラーコードに「#FFFFFF」（白色）を設定する
4. 設定を保存する

---

### 6. 色分け表示と設定変更後の反映確認

1. 一覧画面を表示する
2. 勤続年数が5年以上のユーザーの背景色が「#000000」（黒色）に、5年未満のユーザーの背景色が「#FFFFFF」（白色）になっていることを確認する
3. 設定画面に戻る
4. 「勤続年数5年以上」のカラーコードを「#0000FF」（青色）に、「勤続年数5年未満」のカラーコードを「#FFFF00」（黄色）に変更する
5. 設定を保存する
6. 一覧画面に戻る
7. 勤続年数が5年以上のユーザーの背景色が「#0000FF」（青色）に、5年未満のユーザーの背景色が「#FFFF00」（黄色）に更新されていることを確認する
